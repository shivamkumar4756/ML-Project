# EduScore - Predict Student Math Scores

## 🚀 Project Overview
Welcome to EduScore, a machine learning project designed to predict a student's Math Score based on various factors such as gender, ethnicity, parental education level, lunch type, and test preparation course completion.

## 🔍 Problem Statement
The project aims to understand how the student's performance (test scores) is influenced by:
- Gender
- Ethnicity
- Parental level of education
- Lunch type
- Test preparation course completion

## 📊 Dataset Overview
- **Source**: [Kaggle Dataset](https://lnkd.in/gnjb7P3R)
- **Size**: 1000 rows, 8 columns
- **Description**: Contains details about students and their Math scores, along with other demographic and educational attributes.

## 🚀 Live Prediction Tool
The project has been deployed on AWS Elastic Beanstalk, enabling real-time predictions through a user-friendly web interface.
- **Application Name**: EduScore
- **Live Demo**: [Check it out here](https://lnkd.in/gkpehQZD)

## 🌐 Tech Stack
### Model Development
- **Libraries**: Pandas, NumPy, Seaborn, Matplotlib, Scikit-learn, CatBoost, XGBoost, Dill
- **Framework**: Flask

### Deployment
- **Platform**: AWS Elastic Beanstalk
- **Containerization**: Docker
- **API**: REST API using Flask

## 📊 Model Performance
- **R² Score**: 85.21% (Strong predictive performance)

## 🚀 How to Run the Project Locally
### Prerequisites
1. Python 3.8 or above
2. Required libraries:
   ```bash
   pip install pandas numpy seaborn matplotlib scikit-learn catboost xgboost dill flask
   ```
3. Docker (optional for containerized deployment)

### Steps
1. Clone the repository:
   ```bash
   git clone https://lnkd.in/gQJNS-fi
   ```
2. Navigate to the project directory:
   ```bash
   cd math-score-prediction
   ```
3. Run the Flask application:
   ```bash
   python app.py
   ```
4. Access the application at `http://127.0.0.1:5000` in your browser.
